# Visual and interaction review

Reviewed the rendered essay laboratory, sentence workbench, practice flow, materials library, progress view, and mobile essay layout. Captures and automated results are in `reports/interface-*.png` and `reports/interface-review.json`.

The design uses the essay as the primary reading surface, with a separate explanation column and evidence-linked annotations. Practice is centered on a question and its grammatical relationship; progress metrics use compact, fully outlined panels. Containers that need distinction use a complete border or muted surface, never a vertical accent stripe. All icons and structural SVGs are authored paths; dependency diagrams use actual report tokens and edges. The fixed sidebar has independent overflow so its settings remain reachable on short desktop windows. Mobile navigation scrolls horizontally and the explanation column moves below the essay.

The anti-slop critique found small interface typography and low-contrast navigation indices in the first render. Text sizes were increased, index opacity was removed, and the sidebar overflow issue was corrected. The first workbench render also revealed weak handling of nominal gerunds and dependency attachment; contextual noun tagging and bounded determiner/preposition attachment were corrected and regression-tested. The fallback remains labelled provisional.

Signature-preservation audit: locally bundled Noto Sans only; white/black foundations; blue/red functional accents; 5px rounded controls/surfaces; sentence-case labels; no gradients, glass, stock illustrations, public rankings, badges, or artificial streaks. Square inline annotations and circular loading indicators are not rounded surfaces. Reduced-motion preference disables animation and smooth source navigation. All core functions have labelled controls and visible focus styles.

Automated axe checks cover WCAG 2 A/AA and 2.1 AA tags on the five main desktop views and the mobile essay view. Actual browser workflow tests also cover keyboard access, dialog Escape/focus handling, source-linked correction, undo/redo, persistence, imports, backup restore, and offline use. Automated checks do not establish full accessibility conformance; screen-reader testing with users and physical mobile-device review remain outstanding.

The release refinement removes promotional shell copy and decorative sidebar content, uses a compact navigation/header, raises essay reading text to 15px, and makes findings independently scrollable. Desktop reading and analysis controls remain inside both 1440×900 and 1280×800 viewports. Duplicate source evidence is collapsed visually. The workbench uses actual dependency labels and an aligned parse selector. The latest six-view inspection reports no axe violations, external requests, runtime errors, or horizontal overflow. Updated product screenshots are in docs/images.
