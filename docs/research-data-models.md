# Data and model provenance research

Checked 22 October 2026 against the publishers' own repositories, licenses, distribution metadata, and task websites. All downloads made for this work are inside the project. No learner corpus with a non-commercial or signed-agreement restriction was downloaded by this research task.

## Shipping data: UD English EWT

Use the project's pinned **UD English EWT r2.16**, commit `4c89b5833a70aa5ed3a00bad2f23f57992cc7df8`, rather than a moving branch. The retained manifest records the exact train/dev/test, README, and license hashes. The publisher licenses the corpus CC BY-SA 4.0, permitting commercial use and adaptation with attribution and the applicable share-alike conditions. Preserve contributor attribution, license links/notices, and an account of changes when redistributing derived data. Do not infer that a corpus license automatically settles every possible model-weight licensing question; the candidate's model card should state its chosen distribution terms and provenance explicitly. [Pinned publisher README](https://github.com/UniversalDependencies/UD_English-EWT/blob/4c89b5833a70aa5ed3a00bad2f23f57992cc7df8/README.md), [pinned license](https://github.com/UniversalDependencies/UD_English-EWT/blob/4c89b5833a70aa5ed3a00bad2f23f57992cc7df8/LICENSE.txt).

EWT contains web text from multiple genres, rather than a representative held-out collection of American academic learner essays. Its sentence identifiers encode genre and source filenames. Keep source documents and exact duplicate sentences disjoint across splits; retain the publisher's test split for final reporting. Author and prompt identities are not fully available, so describe the actual split as document-aware rather than claiming verified author/prompt independence. POS accuracy and dependency attachment scores on EWT do not establish grammatical-error precision or educational effectiveness. [Publisher documentation](https://github.com/UniversalDependencies/UD_English-EWT/blob/4c89b5833a70aa5ed3a00bad2f23f57992cc7df8/README.md).

During research, the official r2.18 tag was also resolved to `b7711cce01cdd4f5fcc0a8199b8a50d951b16c0c`; it was not substituted for the already selected r2.16 data. Record a new manifest and rerun evaluation before changing corpus releases. [Official tag API](https://api.github.com/repos/UniversalDependencies/UD_English-EWT/git/ref/tags/r2.18).

## Shipping lexicon: SCOWL-derived American English

Downloaded `index.dic`, `index.aff`, the complete `license`, and `readme.md` from **wooorm/dictionaries**, pinned commit `8cfea406b505e4d7df52d5a19bce525df98c54ab`, into `training/datasets/raw/dictionary/`. Each file's SHA-256 and Git blob hash is recorded in `training/datasets/dictionary-manifest.json` and was verified after writing. The dictionary has 49,568 stem entries; the upstream notice identifies the build as **7 December 2020**, generated using `mk-list --accents=strip en_US 60`. [Pinned source directory](https://github.com/wooorm/dictionaries/tree/8cfea406b505e4d7df52d5a19bce525df98c54ab/dictionaries/en).

The source permits use, copying, modification, redistribution, and sale subject to the included notices. Its full notice retains SCOWL, WordNet, VarCon, Ispell, and component-source conditions. Ship that complete notice alongside redistributed word tables; a lone MIT label does not reproduce it. The maintainer's published `dictionary-en` 4.0.0 distribution lists `(MIT AND BSD)` and an npm archive integrity value, which the manifest retains as a distribution reference. The checked-in Git commit and individual file hashes are the authoritative provenance for this download. [Complete upstream notice](https://github.com/wooorm/dictionaries/blob/8cfea406b505e4d7df52d5a19bce525df98c54ab/dictionaries/en/license), [maintainer README](https://github.com/wooorm/dictionaries/blob/8cfea406b505e4d7df52d5a19bce525df98c54ab/dictionaries/en/readme.md), [publisher's npm metadata](https://registry.npmjs.org/dictionary-en/4.0.0).

The `.dic` entries contain Hunspell affix flags, so they are not an already expanded surface-form list. Apply only the corresponding permitted prefix/suffix rules, respect cross-product flags, exclude `ONLYINCOMPOUND c` stems from standalone-word acceptance, and keep `NOSUGGEST !` forms out of correction suggestions. The original flags and rules remain available for verification. Unknown names or technical terms still require abstention rather than automatic misspelling diagnoses. [Pinned affix rules](https://github.com/wooorm/dictionaries/blob/8cfea406b505e4d7df52d5a19bce525df98c54ab/dictionaries/en/index.aff).

## Learner corpora: access and intended-use restrictions

The official **BEA-2019** task site explicitly restricts the listed learner corpora to non-commercial purposes. FCE and W&I+LOCNESS are directly downloadable, but direct availability does not remove those conditions; NUCLE and Lang-8 also have request procedures. Do not bundle these corpora, or silently train shipping artifacts from them, on the assumption that public download means unrestricted redistribution. Review the actual archive license and intended use before any separately authorized offline research run. [Official data and terms](https://www.cl.cam.ac.uk/research/nl/bea2019st/), [official W&I+LOCNESS v2.1 download](https://www.cl.cam.ac.uk/research/nl/bea2019st/data/wi+locness_v2.1.bea19.tar.gz).

The **CoNLL-2014** publisher separates the freely linked annotated test data/scorer from NUCLE training-data access, which requires a signed license form. Obtain and retain the actual training-data agreement before use. The official BEA overview cautions that the CoNLL test set contains only 50 essays on two topics from 25 Singapore undergraduates; competitive results there do not establish broad American-academic-writing coverage. [Official CoNLL-2014 data access](https://www.comp.nus.edu.sg/~nlp/conll14st.html), [official BEA discussion of benchmark scope](https://www.cl.cam.ac.uk/research/nl/bea2019st/).

The official **UD English ESL / Treebank of Learner English** README explicitly separates its CC BY-SA 4.0 annotations from the underlying FCE text, which is omitted because of FCE licensing restrictions. Its reconstruction instructions require obtaining FCE and signing that corpus's agreement. It describes 5,124 original/corrected learner sentences and a random sentence-level split; that split must not be represented as independently author/document-disjoint. Sentence IDs preserve source document paths that can support a stricter grouped split after licensed text is obtained. The repository exists on `master`; an r2.18 tag was not available at the checked URL. No ESL corpus files were imported as part of this audit. [Publisher README](https://github.com/UniversalDependencies/UD_English-ESL/blob/master/README.md), [annotation license](https://github.com/UniversalDependencies/UD_English-ESL/blob/master/LICENSE.txt).

## Model choice and runtime

Train and export the project's own small discriminative models against explicitly licensed data. A pretrained parser is not automatically a usable browser artifact: its exact weight license, architecture, preprocessing, operator support, size, and evaluation domain must all match this product. For example, the official **UDPipe 2** model page distributes its listed models under CC BY-NC-SA and describes BERT/RobeCzech additions in current editions, so those downloads are not an unrestricted compact ONNX replacement for this project. [Official UDPipe 2 model distribution](https://ufal.mff.cuni.cz/udpipe/2/models).

Published ONNX Runtime Web supports local WebAssembly CPU inference; optional GPU execution providers have more limited operator coverage. Validate the actual exported graph in the browser's published WASM runtime, rather than equating successful Python export or Python ONNX Runtime execution with browser compatibility. Retain a deterministic fallback and disclose model-load failure. [Official ONNX Runtime Web documentation](https://onnxruntime.ai/docs/tutorials/web/).

## Promotion and independent validation

Before enabling a trained artifact, record dataset and artifact hashes, code/configuration/seed/dependency versions, input/output schemas, preprocessing and tokenization rules, quantization, calibration method, supported variety, and known limitations. Test Python/browser prediction parity, not only output shape. In particular, UD multiword tokens and split contractions must be reconciled with the application's UTF-16 source tokens without silently changing source offsets. [Official CoNLL-U representation](https://universaldependencies.org/format.html), [project model manifest schema](../models/manifests/model.schema.json).

Report grammar detection precision/recall and correction acceptance by category on independent annotated essays, with sample counts and uncertainty intervals. Report valid-control false positives separately. Synthetic mutations, development regression fixtures, and syntax-label accuracy answer different questions and cannot substitute for that evaluation. The BEA task uses span-based correction evaluation and explicitly discusses dataset/domain effects. [Official evaluation protocol](https://www.cl.cam.ac.uk/research/nl/bea2019st/).

Qualified independent adjudication, physical-device testing, blind comparative review, and consented pretest/delayed-posttest/transfer studies require actual external observations. Software can implement the study instruments, schema validation, blinded exports, and analysis; it cannot truthfully manufacture their outcomes. Keep unmet empirical gates visible until those observations exist.
