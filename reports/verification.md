- The latest full `make release` run passes all 184 Playwright checks across Chromium, Firefox, WebKit, and mobile Chromium emulation. Coverage includes actual local-model inference, feature parity, offline reload, document persistence and restore, import security, keyboard access, responsive layouts, count-noun review and numeric identifier controls, and learner-controlled corrections.

- The production build succeeds. Initial JavaScript is 84.1 KiB gzip against the 104.7 KiB budget; secondary views and the analysis worker are lazy-loaded. Runtime model inference and document analysis remain local.
- Shipped full EWT component evidence remains 94.47% POS, 81.66% UAS, and 77.27% LAS across 1,962 sentences / 24,859 tokens. These model weights did not change in this work.
- The current browser regression report measures 93.50%/81.91%/77.81% POS/UAS/LAS over 300 EWT sentences / 3,659 gold tokens. It aligns 3,610 tokens and exactly tokenizes 266 sentences. The sample spans five source genres and counts unmatched tokens as incorrect. It was inspected during tokenizer development, so it is not an untouched confirmatory test.
- The fixed browser scores improve 1.31/1.75/1.72 absolute points over the original POS/UAS/LAS baselines, below the requested five-point floor. The full EWT parser goals and the million-token POS claim remain unmet.
- The goal map contains 97 general writing goals: 31 connected to unvalidated local detectors and 66 still labeled `not-yet-detectable`. The count-noun plural detector uses stable local parse and training-lexicon evidence, abstains on numeric identifiers governed by an indefinite article, and emits no correction. The gerund-complement rule reviews only a stable neural `xcomp` for finite `enjoy` or `avoid` followed immediately by `to` and an infinitive; it also emits no correction. No pattern has independent evidence for the requested precision, recall, valid-control, and correction-acceptability gates. The comparison tool now evaluates those requirements per declared annotation subtype instead of allowing category aggregates to mask a weak pattern.

On 26 authored clean probes, there are zero conservative false positives and one review warning. These authored and synthetic checks do not establish learner-writing accuracy.
- The latest generalization run checks source/edit integrity on all 411 cases and 219 proposed edits. Correction integrity verifies source spans and edit transactions; it does not establish that a proposed change preserves meaning.
